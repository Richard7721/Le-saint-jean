# Le Saint-Jean · Bureau à louer à Melun

Site vitrine statique (HTML, CSS, JavaScript sans framework) pour la location du bureau Le Saint-Jean, 3 rue de l'Éperon, 77000 Melun.

## Contenu

- `index.html` : page d'accueil (calendrier de disponibilités, formulaire de visite ou de réservation, FAQ, accès)
- `mentions-legales.html` : mentions légales et confidentialité
- `assets/` : photos et plan d'accès (© contributeurs OpenStreetMap)

## Déploiement sur Vercel

1. Importer ce dépôt GitHub dans Vercel (Add New > Project).
2. Framework Preset : **Other**. Aucune commande de build, dossier de sortie : racine.
3. Deploy.

## Formulaires

Les formulaires ouvrent la messagerie du visiteur avec un email prérempli vers yn@sayah.com. Pour recevoir les demandes sans passer par la messagerie du visiteur, brancher un service de formulaires (Formspree, Web3Forms) ou une fonction Vercel.

## À compléter

Les mentions entre crochets `[...]` : délai de réponse, préavis, conditions de la salle de réunion, charges, courrier, numéro WhatsApp, mentions légales de l'exploitant.
